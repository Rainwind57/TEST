一、项目概述

本平台是一套前后端分离的 A 股量化研究系统：后端基于 FastAPI（端口 8899），提供行情、因子、回测、机器学习、组合优化、风险归因等 REST API；前端基于 Vue 3 + Vite（端口 5899），提供完整可视化界面。


核心能力链路：数据接入 → 因子计算 → 选股打分 → 分层回测 / 分钟回测 → 模拟盘 / 策略归档 → 组合优化 → 风险归因，支持 ML 模型打分、人工调参、参数寻优，全流程中间结果可落盘复用。

二、快速上手

环境要求

  • Python 3.10+（开发环境 3.14），Node.js 18+
  • 依赖：fastapi uvicorn httpx numpy pandas scikit-learn lightgbm optuna cvxpy joblib apscheduler openpyxl
  • 数据库：SQLite（backend/quant.db，首次启动自动建表）

启动后端

# 终端 1
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8899

健康检查：浏览器打开 http://127.0.0.1:8899/api/health 应返回 {"status":"ok"}。

启动前端

# 终端 2
cd frontend
npm install
npm run dev

浏览器访问 http://127.0.0.1:5899，首次使用点击「注册」创建账号（也可匿名使用，但策略/存档按用户隔离）。

Docker 部署（可选）

docker compose up -d

根目录 docker-compose.yml 同时编排前后端容器。

三、功能总览

行情

/quote

自选股实时行情（腾讯/新浪/东财三源）、分时与日 K 线、涨跌统计。

数据市场

/data

期货行情与日 K 线（中金所 + 商品全品种）、宏观指标（CPI/PPI/PMI/M2）、指数成分股。

因子

/factor

40+ 因子计算：量价（动量/波动率/乖离）、估值、资金流、北向持股，按分组查看截面。

回归

/regression

单因子与未来收益回归，输出 R²、RankIC，一键带因子去分层回测。

多因子回归

/factor-regression

Fama-MacBeth 截面回归，因子收益时序列、t 统计量、胜率、显著性检验。

选股

/select

多因子加权打分（权重/方向可编辑）、时间区间回看、自定义股池、ML 模型选股、结果落盘复用。

分层回测

/backtest

分组回测（IC / 多空组合 / 分组收益）、交易成本、报告导出（HTML/Excel）、自定义股池。

模拟盘

/portfolio

模拟买卖、持仓盈亏、资金曲线、支持一键等权买入选股结果。

策略中心

/strategies

自定义组合因子（加权 z-score）、策略一键运行、回测存档。

机器学习

/ml

GBDT/LightGBM 训练（Walk-Forward CV）、超参寻优、截面打分选股、ML 信号回测、人工调参。

盯盘调度

/monitor

定时扫描动量/RSI 信号、可持久化的自动开关、重启恢复运行状态。

参数寻优

/optimize

网格搜索策略参数并回测验证，最优参数一键回写策略 / 应用回测。

组合优化

/portfolio-opt

均值方差 / 最大夏普 / 风险平价等权求解，历史数据自动估计 μ/Σ。

分钟回测

/intraday

分钟级日内策略回测（含 T+1、成本、止盈止损），支持多标的同时评估。

风险归因

/risk

Barra 风格风险分解（动量/波动/换手/EP/BP/市值）、VaR/CVaR、支持任意自定义组合。

四、各模块使用说明

1. 行情 行情页

  1. 在输入框输入 6 位代码（如 600519）或带前缀（sh600519）后点「添加」；
  2. 左侧列表点击股票查看实时行情与 90 日 K 线；
  3. 「手动刷新」强制拉取最新价，「删除」移出自选。

2. 数据市场 数据市场页

  • 期货行情：输入合约代码查询，如 IF2608（股指）、rb2610（螺纹钢）、au2612（沪金）、AU0（主连）。点「K线」查看日 K 图；
  • 宏观指标：自动展示 CPI / PPI / PMI / M2 最新一期数值与月份；
  • 指数成分：加载沪深300 / 中证500 成分股，一键把前 50 只加入自选。

3. 因子 因子页

选择分组（量价/估值/资金流等）→ 点「计算自选股因子」查看因子截面表。技术因子基于近 260 日 K 线，量能/基本面因子来自实时行情快照。

4. 回归 & 多因子回归

  • 单因子回归：选板块与因子 → 运行回归 → 看散点/拟合线与 RankIC → 「用该因子回测」跳转分层回测；
  • 多因子回归：用复选框勾选 ≥2 个因子 → 运行，输出各因子平均收益、t 统计量（|t|≥2 显著）、胜率，点「用显著因子回测」。

5. 选股（多因子加权打分）核心

  1. 选板块、候选池规模、Top N；
  2. 勾选参与打分的因子，编辑每个因子的权重（数字框）与方向（正向/反向）——未勾选因子也可提前编辑权重，勾选后生效；
  3. 可填时间区间 startDate/endDate 做历史截面选股，或填自定义代码池；
  4. 也可填模型 ID 走 ML 预测分选股（调参配置自动生效）；
  5. 点「运行选股」得到排名与综合得分，结果可「加入自选 / 一键买入模拟盘 / 用该股池回测 / 保存为中间结果」。

行业 / 宏观因子（方向=不参与）仅作信息展示，不稀释综合得分。

6. 分层回测 核心

  1. 选择板块（或在上方「中间结果 ID」填入选股页保存的 ID，使用自定义股池）；
  2. 选策略来源：技术因子（选因子）或 ML 模型；设定分组数、持有天数 N、历史长度、基准；
  3. 可勾选「启用交易成本」（佣金/印花税/滑点）；
  4. 运行后查看分组收益、IC / RankIC 时序、多空累计曲线与全部绩效指标；
  5. 「保存为策略 / 导出 HTML / 导出 Excel」归档与输出。

7. 模拟盘 模拟盘页

选择自选股 → 切换「买入/卖出」→ 输入数量与价格下单；资产卡片实时展示总资产/持仓/盈亏，资金曲线可回看。

8. 策略中心

  • 自定义因子：添加多行「成分因子 + 权重 + 方向」加权合成新因子，保存后可在选股中使用；
  • 策略：保存的策略一键运行 → 回测 → 自动归档关键指标。

9. 机器学习 ML

  1. 设参数（模型类型、CV 折数、历史长度，可勾选含快照因子）→「评估(CV)」/「训练并落盘」；
  2. 已训练模型可「打分选股」「ML回测」「去主回测」；
  3. 人工调参：点「调参」展开面板，调整各特征权重与预测阈值偏移 → 「保存调参配置」，之后打分/回测自动应用；
  4. 「删除」清理模型文件。

10. 盯盘调度

点击「启动 / 停止」开关（默认状态持久化，重启服务自动恢复）。运行后每个交易日 15:10 自动扫描自选股动量/RSI 信号并生成报告。

11. 参数寻优 / 组合优化

  • 参数寻优：设参数范围与步长 → 开始寻优 → 看最优组合的绩效；「回写为策略 / 应用到回测」一键流转；
  • 组合优化：输入代码 → 「从代码自动生成 μ/Σ」→ 选择方法（均值方差/最大夏普/风险平价/等权）→ 求解得到权重与组合统计，「应用组合」买入模拟盘。

12. 分钟回测

输入单只股票或代码列表（≤50 只），设日内信号参数、止盈止损、成本 → 开始回测，输出每笔交易、胜率、per-trade Sharpe。

13. 风险归因

  • 模拟盘持仓归因：一键对当前持仓做 Barra 风格分解；
  • 自定义组合归因：输入代码（可带权重）→ 对任意组合做风格暴露 / 因子贡献 / VaR-CVaR 分析。

五、研究流水线（中间结果复用）

平台支持跨页面闭环研究，中间结果落盘为 artifact 供下一环节复用：

选股（保存为中间结果）
  │  └─ /api/artifacts 生成 ID（如 20260803_162832_b184ac）
  ▼
分层回测（填入中间结果 ID 载入自定义股池）
  │  └─ 回测结果也可保存为 artifact
  ▼
组合优化 / 风险归因（读取 codes 或直接粘贴）
  │
  ▼
模拟盘 / 策略归档

ML 链路同理：训练 → 调参（adjustId）→ 打分选股 / ML 回测，调参配置随 artifact 持久化，重启不丢。
