## 一、K 线图：不能缩放、无分时图（用户反馈①）

### 1.1 行情详情页 K 线功能单薄（确认）
`frontend/src/views/QuoteView.vue`：
- `klineOption`（52-66 行）只画了 `candlestick`（蜡烛），**没有 `dataZoom` 配置** → 无法框选/滚轮放大缩小。
- 仅 1 个 `series`，**无 MA 均线、无成交量副图、无 MACD 等常见技术指标叠加**。
- `loadKline()`（47 行）硬编码 `days: 500`，**无日/周/月/年级别切换**，也无"前复权/后复权"切换入口（后端 `fetch_kline` 默认 `qfq`，adapters.py:464）。

> 结论：用户"K 图不能放大缩小"属实；行情页是一张静态日 K 蜡烛图，缺少量化看盘最基本的缩放、均线、量能、周期切换。

### 1.2 完全没有"分时图"（确认）
- 全前端搜索"分时"无任何匹配；`adapters.py` 只有 `fetch_minute_kline`（分钟 K 线，731 行），**没有分时（time-share，含均价黄线、9:30–15:00 连续价格走势）数据接口**。
- `QuoteView.vue` 只调用日 K（`/kline`），**从未调用分钟数据**，因此行情详情页看不到分时。
- 分钟数据仅被"分钟回测"（`IntradayView`）用于回测计算，并未作为"看盘图表"呈现给用户。

> 结论：用户"没有分时图可以看"属实。平台有分钟**K线**数据能力，但缺分时**图**这一看盘高频视图，且行情页未接入分钟数据。

### 1.3 分钟回测可视化偏弱
`frontend/src/views/IntradayView.vue`：
- 只渲染了一条"累计盈亏曲线"（`pnlOption`，57-72 行，123-126 行），**没有标的价格走势 + 买卖点标记的图谱**，不便于复盘信号质量。

## 二、回测报告：能否形成？（用户反馈③）

**结论：能形成，且能力完整。** 证据：
- 前端导出按钮齐全：`BacktestView.vue:320-322` 有「导出HTML / 导出Excel / 导出PDF」三个按钮，且 `disabled` 逻辑绑定 `!result`（有回测结果才可用，合理）。
- 报告历史：`BacktestView.vue:325+` 展示回测完成自动存档的列表，支持下载/重生成/删除。
- 后端路由完整：`backend/app/routers/reports.py` 提供 `/api/reports/backtest`（导出）、`/runs`（历史）、`/runs/{id}`（下载）、`/runs/{id}/regenerate`（重生成 html/excel/pdf）、`/runs/{id}` DELETE。
- 自动存档：回测完成会自动调用 `reporting.store_backtest_report`（如 `ml.py:1068`），磁盘 `backend/reports/` 已有 `report_*.html` 佐证。
- 依赖就绪：`requirements.txt:5` 含 `openpyxl>=3.1`、`requirements.txt:15` 含 `reportlab>=4.0`；实测运行环境二者均已安装（openpyxl 3.1.5）。

### 2.1 报告的体验短板（仍可优化）
1. **HTML 报告图表强依赖外网 CDN**（高优先）：`reporting.py:101` 内嵌
   `<script src="https://cdn.jsdelivr.net/npm/echarts@5/...">`。
   在国内网络/离线环境下 CDN 常被墙或超时 → **下载的 HTML 报告只有 KPI 卡片和表格，图表空白**。这是"报告能形成但图表打不开"的隐患。建议改为打包本地 ECharts 或内联。
2. **PDF 报告仅文字、无图表**（中优先）：`render_pdf`（217-312 行）只 `drawString` 输出 KPI 文字，**不含任何净值/回撤/分组/IC 图**。导出的 PDF 可读性弱于 HTML。
3. **报告无应用内预览**：`/reports/backtest` 返回 `attachment` 下载头，用户只能下载文件用浏览器打开，应用内无报告预览页。

## 三、其他不足（用户反馈②"依旧帮我找不足"）

### 3.1 图表交互通用问题
- `EChart.vue` 是极薄封装（`chart.setOption(props.option, true)`），所有交互能力取决于各视图传入的 `option`。多处图表（行情 K 线、因子回归、选股等）都未加 `dataZoom`，**缩放是平台级缺失**，不只行情页。

### 3.2 行情页数据维度浅
- `QuoteView.vue:47` 取 `days:500`，但结合前两篇文档已确认：适配器层新浪封顶 1023、东财封顶 500（adapters.py:468/495），且 UI 历史长度上限 360（BacktestView/FactorRegressionView）。**即便加了缩放，可缩放的历史范围也被压得很窄**——缩放与"数据深度不足"问题叠加。

### 3.3 分钟回测与看盘割裂
- 平台既能取分钟数据（`fetch_minute_kline`）又能跑分钟回测，却**没有"分钟级看盘/分时监控"视图**：分时图缺位、分钟回测无价格图谱。分钟数据价值未被充分释放。

### 3.4 复权/周期不可选
- 后端 `fetch_kline` 仅支持前复权 `qfq`（adapters.py:464），前端无任何复权或日/周/月切换控件。长期持仓回测若需后复权需改代码。

### 3.5 报告与"模块共享"未打通（呼应首批③）
- 回测报告是孤立产物：ML 模型回测报告、选股报告、因子回测报告各自生成，**没有统一的"策略/模型成果库"把报告与可重跑的策略关联起来**，与第一篇"模型模块间共享不足"一致。

## 四、优先级建议

| 优先级 | 问题 | 位置 | 建议 |
|--------|------|------|------|
| P1 | K 线无 dataZoom、无 MA/量能、无周期切换 | QuoteView.vue:52-66 | ECharts 加 dataZoom+dataZoomInside、MA 序列、成交量副图、周期 tab |
| P1 | 无分时图 | adapters.py 缺分时接口 + QuoteView 未接入 | 新增分时数据接口（均价黄线）+ 行情页分时 tab |
| P1 | 报告 HTML 图表依赖 jsdelivr CDN | reporting.py:101 | 内联/本地化 ECharts，离线可用 |
| P2 | PDF 报告无图表 | reporting.py:217-312 | 接入 matplotlib 生成净值/回撤图嵌入 PDF |
| P2 | 分钟回测无价格+买卖点图谱 | IntradayView.vue:57-72 | 增加标的价格曲线与进出场标记 |
| P2 | 复权/周期不可选 | adapters.py:464 + QuoteView | 前端加 qfq/hfq 与日/周/月切换 |
| P3 | 报告无应用内预览 | reports.py 全链路 | 增加报告预览路由/页面 |

## 五、与既有清单的关联
- **数据深度（第二篇）** × **图表缩放（本篇）**：历史被压在 90–1023 天，即使加了缩放也"无米之炊"。
- **模块共享不足（第一篇③）** × **报告孤立（本篇 3.5）**：报告未与可重跑策略关联。
- **timeout/慢（第二篇）**：报告渲染、图表数据拉取若仍走无连接池的 `_http_get`，缩放/分时频繁刷新会进一步放大卡顿。

> 注：以上均为只读诊断结论；如需针对某条出修复补丁，可单独提出。
