## 五、发现的缺陷（已修复并复验）

### 缺陷 #1：`POST /api/optimize/save-strategy` 键缺失即 400（健壮性 bug）— 已修复 ✅

- **现象**：baseConfig 传 `{"factor":"momentum"}` → `400 保存失败: 'board'`
- **根因**：`backend/app/optimize.py:140` `save_best_as_strategy()` 用 `base_config["board"]`、`["hist"]`、`["commissionRate"]`、`["stampDuty"]`、`["slippage"]`、`["benchmark"]`、`["applyCost"]` 硬取键；但这些字段在 `OptimizeBody` 中本有默认值，baseConfig 字典缺键即 `KeyError`。
- **影响**：前端 `OptimizeView` 若未把完整 OptimizeBody 字段塞进 baseConfig 则保存失败；`/api/optimize/backtest` 寻优成功后调本端点也会因同样的键缺失而失败。
- **修复**：改 `base_config.get("board", "all")` 等带默认值的取法，默认值与 `OptimizeBody` 一致；`best_params` 同样改 `.get` 兜底。
- **位置**：`backend/app/optimize.py:140-155`
- **复验**：minimal baseConfig `{"factor":"momentum"}` → 200，config 自动补全默认值。
- **严重度**：中（功能性，非崩溃）→ 已清零

### 缺陷 #2：`POST /api/intraday/backtest` 分钟 K 线上游接口已失效（真实 bug）— 已修复 ✅

- **现象**：`502 分钟级回测失败: Expecting value: line 1 column 1 (char 0)`，重定向后 `502 ... getaddrinfo failed`
- **根因**：`backend/app/adapters.py:623` 原调腾讯分钟接口 `https://web.ifzq.gtimg.cn/...mkline/get`，上游已返回 **301 Moved Permanently** 跳转 `web3.ifzq.gtimg.cn`（HTML 重定向页，非 JSON）。`httpx` 默认不跟随重定向 → `resp.json()` 解析 `<html>...` 抛 `JSONDecodeError`；即便跟随，`web3.ifzq.gtimg.cn` 在当前网络 DNS 解析失败。
- **验证**：直接 curl 原腾讯 URL → 301 HTML；新域名 `web3.ifzq.gtimg.cn` → `getaddrinfo failed`。
- **影响**：`/intraday` 分钟回测功能当前**完全不可用**；依赖它的 `strategies/{sid}/run`（kind=intraday）也失效。
- **修复**：
  1. `_http_get`（`adapters.py:31`）统一加 `follow_redirects=True`，所有上游接口自动跟随重定向，根治同类问题。
  2. `fetch_minute_kline`（`adapters.py:612`）改用新浪分钟接口 `money.finance.sina.com.cn/.../getKLineData`（稳定、直接返回 JSON、本环境可达），字段映射 `day`→`datetime`、`open/high/low/close/volume`，带 `_SINA_HEADERS`。
- **位置**：`backend/app/adapters.py:25-37`（`_http_get`）、`backend/app/adapters.py:612-644`（`fetch_minute_kline`）
- **复验**：`POST /api/intraday/backtest` → 200，返回 `{"trades":[],"metrics":{...},"nBars":48,"period":"5"}`。
- **严重度**：高（功能完全不可用）→ 已清零

### 非缺陷说明（合理校验，无需修复）

| 项 | 现象 | 结论 |
|---|---|---|
| `select/backtest` 小样本 422 | poolSize=20/hist=30 → 422 "有效截面样本不足" | 合理校验，加大参数即 200 |
| `risk/attribution` 空持仓 422 | 无持仓 → 422 | 合理校验 |
| `auth/me` 无 token 401 | 未登录 → 401 | 正确鉴权 |
| `jobs/{jid}` cancel 404 | 已完成任务 → 404 | 合理 |
| `QUANT_JWT_SECRET` 警告 | 随机密钥警告 | 部署配置项，生产环境需设置环境变量 |
