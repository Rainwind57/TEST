## 〇、启动环境（先做这一步）

**后端**（终端 1，在 `backend` 目录）：
```bash
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8899
```
- 健康检查：浏览器打开 `http://127.0.0.1:8899/api/health`，应返回 `{"status":"ok"}`。

**前端**（终端 2，在 `frontend` 目录）：
```bash
npm install   # 首次需安装依赖
npm run dev
```
- 浏览器访问 `http://localhost:5899`。

> 前端直连后端 `http://127.0.0.1:8899/api`（CORS 白名单已含 5899）。若换端口访问，需设置后端环境变量 `QUANT_CORS_ORIGINS`。

**页面导航**：左侧边栏菜单，从上到下为「行情 / 数据市场 / 因子 / 回归 / 多因子回归 / 选股 / 分层回测 / 模拟盘 / 策略中心 / 机器学习 / 盯盘调度 / 参数寻优 / 组合优化 / 分钟回测 / 风险归因」。

> 涉及写操作（保存因子/模型/报告等）需先登录（右上角「登录 / 注册」）。

## 〇.5、新用户快速上手（5 分钟跑通）

> 给第一次使用的人：按此顺序操作即可完成一次"选股→回测→ML 建模"的完整流程。

1. **登录**：右上角「登录 / 注册」→ 注册一个账号（写操作都需要登录态）。
2. **行情页建自选池**：「行情」→ 输入代码（如 `600519` / `830799`）→「添加」，加 3~5 只自选股。
3. **选股**：「选股」→ 板块选「全部A股」，勾选 2~3 个因子（默认已勾动量/换手/PE）→「运行选股」→ 得到打分排序。
4. **回测**：选股结果区点「用该股池回测」→ 跳「分层回测」→ 点「运行回测」→ 看净值曲线/分组收益，点「导出PDF」「报告历史」验证报告。
5. **机器学习（可选进阶）**：「机器学习」→ 默认参数点「评估(CV)」看因子预测力 →「训练并落盘」得到模型 → 模型行「ML回测」/「打分选股」→「调参」反复迭代（详见 `ML训练验证调参流程说明.md`）。
6. **盯盘（可选）**：「盯盘调度」→ 信号引擎选「ML模型打分」→ 选模型 →「保存配置」→「开启调度」。

## 三、常见问题排查

| 现象 | 可能原因与处理 |
|---|---|
| 打开页面白屏 / 接口 502 | 后端未启动或端口不对；确认 8899 健康检查通过 |
| 前端跨域被 访问地址须为 `localhost:5899` 或 `127.0.0.1:5899`；换端口需设后端 `QUANT_CORS_ORIGINS` |
| 「行业板块」分组不显示 | `/api/data/sectors` 拉取失败（需联网访问东财）；后端日志可见 502 |
| 北交所 K 线空白 | 腾讯接口对 bj 返回空时自动降级新浪/东财；偶尔网络波动可点「手动刷新」重试 |
| 盯盘信号表为空 | 调度器按交易日 15:10 执行；可检查「上次执行」状态与后端日志（`scan_signals` 失败会记录 error） |
| 导出 PDF 变成打印样式 HTML | 后端未安装 `reportlab`，自动降级；`pip install reportlab` 后重启后端即可 |
| 保存因子/模型提示未登录 | 写操作需登录：右上角「登录 / 注册」 |
| 小样本评估报错信息长 | 属正常（P9 结构化报错），按建议调大候选池/历史即可 |
