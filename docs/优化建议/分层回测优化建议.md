# 分层回测（ML 信号）优化建议

> 针对投诉：① 分层回测不可以只选择做多还是做空；② 回测报告缺失很多关键信息。
> 全部结论基于当前代码逐行复核（非凭记忆）。核心代码位置：
> - 回测主流程：`backend/app/ml.py`  `backtest_model`（:1044）→ 分组与多空组合（:1289-1410）
> - 报告渲染：`backend/app/reporting.py`  `render_html`（:90）/ `payload_from_result`（:64）
> - 前端回测入口：`frontend/src/views/MLView.vue`  `runMLBacktest`（:235）/ 配置项（:240）
> 
> 约定：本建议原为纯诊断，现已按 P0+P1+P2 全部落地实现（见第 6 节「实施记录」）。

## 0. 现状实证

### 0.1 长短仓是写死的"多空双腿"
`ml.py:1298-1318` 每个调仓日把候选股按预测分分入 `groups` 组，**固定**最高组做多、最低组做空，组合收益 `ls_ret = top_ret - bottom_ret`（:1301）。函数签名与前端 `config` 均无"方向"概念，因此前端没有任何"只做多 / 只做空 / 多空"的切换控件。

### 0.2 报告已渲染的字段
KPI：累计收益 / 年化收益 / 年化波动 / Sharpe / Sortino / 最大回撤 / Calmar / 胜率（reporting.py:238-247）。
表格：分组平均收益+样本数（:250-255）、基准对比（累计/年化/Sharpe/Alpha/Beta，:258-271）。
图表：合并多空累计净值+回撤（:355）、分组收益、IC 序列、持仓图（positionLedger 非空才显示）。
解读：结果文字解读（:308-314）。

### 0.3 数据与报告的落差（决定"缺失什么"）
`backtest_model` 的 `result`（:1400-1410）其实**已算很多字段**，但报告没渲染：
- `metrics` 里有 `sortino / calmar / topGroupCumReturn / topGroupAnnualized / costRate / applyCost`（:1350-1364）——除了 sortino/calmar，topGroup 与成本相关字段未展示；
- `benchmark` 里算过策略侧 alpha/beta（`_alpha_beta` 返回对齐序列，:1376），但报告基准表**只把基准侧 alpha/beta 填进表，策略侧硬编码为 "-"**（:268-269）；
- `icIr`（信息比率）在 result（:1403）但不进报告；
- `positionLedger` 每期含 `long[] / short[]` 具体代码（:1311-1317），报告不披露；
- `survivorshipBiasWarning`、`histWarning` 在 result（:1409、:1411）但报告完全不显示。

## 1. 问题 A：无法选择做多 / 做空（核心缺口）

### 根因
方向是硬编码的多空双腿，缺 `direction` 参数与 UI 控件。这同时导致"报告只能看合并多空"——因为空头单腿从没被单独输出。

### 优化设计
**A1. 后端 `direction` 参数（P0）**
`backtest_model(mid, board, pool_size, groups, n, direction="long_short", ...)`，`direction ∈ {long_short, long_only, short_only}`。
- `long_short`：维持现状 `ls_ret = top_ret - bottom_ret`；
- `long_only`：仅多头腿，`ls_ret = top_ret - cost_rate`，`position_ledger` 的 `short=[]`；
- `short_only`：仅空头腿，`ls_ret = -(bottom_ret) - cost_rate`（空头收益为正向），`position_ledger` 的 `long=[]`，并明确"空头组合（融券）"标签。

**A2. 报告按方向渲染（P0）**
- `long_short`：保留合并多空净值 + **新增多头单腿、空头单腿两条独立净值线**（数据里 `topCum` 已有，:1309；空头单腿需在 `long_short_points` 增加 `bottomCum` 字段）；
- `long_only` / `short_only`：主图只画对应单腿，KPI 标题随之变化（如"多头组合年化"）。

**A3. 前端方向控件（P0）**
在 `MLView.vue` 回测卡片（约 :615 区、`groups` 选择旁）增加：
```html
<div class="field">
  <label>交易方向</label>
  <select v-model="btDirection">
    <option value="long_short">多空对冲</option>
    <option value="long_only">仅做多</option>
    <option value="short_only">仅做空</option>
  </select>
</div>
```
`runMLBacktest` 的 `config`（:240）追加 `direction: btDirection`，并透传到 `/jobs` 与 `backtest_model`。

**验收**：选"仅做多"→ 报告只出现多头组合曲线、空头持仓为空；选"仅做空"→ 出现空头组合曲线。

## 2. 问题 B：回测报告缺失的关键信息

逐项列出缺失项 + 改造方案（均在 `reporting.py` 落地，数据后端已具备或易补）。

### B1. 策略侧 Alpha / Beta 缺失（P0）
现状基准表策略侧 Alpha/Beta 是 "-"（:268-269）。`_alpha_beta` 已返回对齐序列（:1376），只需把策略相对基准的 alpha/beta 也计算并填入。
改造：在 `backtest_model` 用 `_alpha_beta(aligned_ls, aligned_bench)` 得到策略 alpha/beta，写进 `bench_metrics`；报告基准表增加"策略 Alpha / Beta"两行。

### B2. 多 / 空单腿独立净值未展示（P0，与 A2 联动）
现状只有合并多空净值（:355）。增加：
- `long_short_points` 补 `bottomCum`（空头腿累计）；
- 图表新增多头单腿线（`topCum`）、空头单腿线（`bottomCum`），图例区分，配合 A2 的方向开关显隐。

### B3. 分组绩效残缺（P1）
现状分组表仅 `avgReturn + sample`（:250-255）。补充每组的**年化收益 / Sharpe / 最大回撤 / 累计收益**，并在分组收益图里绘制**每组净值曲线**（而非单点均值）。
改造：在 `backtest_model` 为每个 bucket 维护一条净值序列（`bucket_equity[g]`），随 `groupSummary` 一并返回；报告表格与图同步增强。

### B4. 换手率 / 成本分解缺失（P1）
`metrics` 有 `costRate / applyCost`，但报告未展示（:1350-1364）。补充：
- 换手率（turnover）：由 `positionLedger` 相邻期 long/short 集合差异计算，新增 `metrics.turnover`；
- 报告新增"交易成本影响"卡片：单边成本、年化换手、成本对 Sharpe 的侵蚀（含成本 vs 除成本对比）。

### B5. 持仓明细 / 个股贡献不披露（P1）
`positionLedger` 每期含 `long[]/short[]` 具体代码（:1311-1317），报告从不渲染。新增"持仓明细"表/折叠区：
- 显示最近 N 个调仓期的多/空持仓代码；
- 个股累计贡献（每只票在组合中的收益贡献求和，可由 `position_ledger` + 期间收益反推）。

### B6. IC 统计残缺（P1）
现状仅 平均 IC / IC 胜率 / 截面数（:283-284）。`result` 里已有 `icIr`（:1403，信息比率）但未渲染；缺 **IC 的 t 值 / p 值（统计显著性）**。
改造：在 `information_coefficient_stats` 返回 `tStat / pValue`，报告 IC 卡片展示 平均 IC / RankIC / ICIR / t 值 / 显著性。

### B7. 无分年度绩效（P2）
补充按自然年拆分的年度收益表（从 `long_short_points` 按年聚合），便于识别年度衰减。

### B8. 基准对比易空 + 策略侧不透明（P1，与 B1 合并处理）
现状无默认基准，且表内策略 Alpha/Beta 为 "-"。改造：
- 前端回测默认带一个宽基基准（如沪深300 `sh000300`）可选可关；
- 报告基准表补齐策略侧 alpha/beta（见 B1）。

### B9. Excel / PDF 报告无图（P2，历史遗留）
`render_excel`（:423）/PDF 仅文本表格，无图表。建议导出时附"多空净值图 + 分组图"的 PNG（用 matplotlib 在后端生成嵌入），与 HTML 报告对齐。

### B10. 风险/前视警告未在报告渲染（P1）
`result` 含 `survivorshipBiasWarning`（:1409）、`histWarning`（:1411），但报告不显示。在报告顶部增加"数据与口径说明"卡片，展示：幸存者偏差提示、历史长度自动调整说明、有效区间、有效样本数、成本假设。

### B11. 多空收益分解缺失（P2）
在合并多空净值旁，补充"多头贡献 vs 空头贡献"分解（多腿收益、空腿收益分别累计），帮助理解对冲来源。

## 3. 改造草图（核心片段）

### 3.1 后端 `backtest_model` 方向分支（示意）
```python
direction = (direction or "long_short").lower()
if day_buckets[0] and day_buckets[-1]:
    top_ret, bottom_ret = mean(day_buckets[-1]), mean(day_buckets[0])
    if direction == "long_only":
        ls_ret = top_ret - cost_rate
        net_ls = ls_ret
        short_codes, bottom_cum = [], 0.0
    elif direction == "short_only":
        ls_ret = -(bottom_ret) - cost_rate      # 空头收益正向化
        net_ls = ls_ret
        long_codes, top_cum = [], 0.0
    else:  # long_short
        ls_ret = top_ret - bottom_ret
        net_ls = ls_ret - 2.0 * cost_rate
    cum *= (1.0 + net_ls)
    long_short_points.append({
        "date": date_t, "longShort": net_ls, "cum": cum - 1.0,
        "topCum": cum_top - 1.0, "bottomCum": ..., "gross": ls_ret,
    })
```

### 3.2 报告 Alpha/Beta 补齐（示意）

ab_strategy = _alpha_beta(aligned_ls, aligned_bench) if len(aligned_ls) > 1 else {"alpha":0,"beta":0}

### 关键实现细节
- `direction ∈ {long_short, long_only, short_only}`；long_only 收益 = `top_ret - cost_rate`，short_only = `-(bottom_ret) - cost_rate`，long_short 双腿各扣一份成本。
- 路由透传：`routers/ml.py` `MLBacktestBody.direction`、`routers/jobs.py`、`routers/selection.py`（`longOnly→long_only`）。
- 报告导出补字段：`routers/reports.py` `ExportBody` 增 `direction/survivorshipBiasWarning/snapshotWarning/histWarning/icIr/icTStat/icPValue/yearlyReturns/stockContribution/bucketDates`，前端 `MLView.vue`/`BacktestView.vue` 导出同步透传。

**验收**：选"仅做多"→ 报告只出多头组合曲线、空头持仓为空；选"仅做空"→ 出空头曲线；基准表策略 Alpha/Beta 非 "-"；报告含分组净值曲线/成本卡/年度绩效/个股贡献/持仓明细/ICIR+t值。
