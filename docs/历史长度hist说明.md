# 历史长度（hist）参数说明

## 概述

`hist`（历史长度）是拉取 **K 线数据的总窗口天数**，不是回测天数。回测区间由起止日决定，`hist` 保证回测起点有足够的历史数据来计算因子值。

## 原理

```
  ←── 因子窗口 ──→←────── 回测区间 ──────────→
                    ↑                        ↑
                起始日                    结束日
  ←────────────── hist = 因子窗口 + 回测区间 ────→
```

每次回测调仓都需要计算因子值，而因子值依赖往前看一段历史数据：

| 因子 | 所需历史窗口 |
|------|------------|
| RSI(14) | 14 天 |
| MACD | 26 天 |
| momentum60（60日动量） | 60 天 |
| momentum120（120日动量） | 120 天 |
| **dist_52w_high（距52周新高）** | **240 天** |

## 各模块默认值

### 分层回测（BacktestView）

```
hist = max(300, 回测天数 + 240)
```

- **240**：最长因子（dist_52w_high）所需历史窗口
- **60**：回测暖机（warmup），前 60 根 K 线用于建立因子计算的初始状态
- **300**：底线 = 240 + 60

示例：
| 回测区间 | 天数 | hist |
|---------|------|------|
| 2025-10-12 → 2026-08-10 | 302 | max(300, 302+240) = **542** |
| 2026-01-01 → 2026-06-01 | 151 | max(300, 151+240) = **391** |
| 2026-07-01 → 2026-08-01 | 31 | max(300, 31+240) = **300** |
| 未选起止日 | — | **300**（默认） |

### 机器学习（MLView）

```
min_hist = 240（最长因子窗口）+ n（持有期）+ 1
```

- 前端默认：**500** 天
- 后端默认：**1024** 天（`ML_DEFAULT_HIST`）
- 后端会自动抬升：如果传入的 hist 小于 `min_hist_for_ml(n)`，强制抬升至最小值

### 选股（SelectView）

选股模块不直接暴露 hist 参数，由后端根据板块规模自动拉取。

## 能否手动改小

**可以。** hist 的联动值是保守安全值，覆盖所有内置因子。如果确认只使用短窗口因子（如 RSI、MACD、成交量类因子），可在输入框中手动改小。但需注意：

1. 回测至少需要 60 天暖机 + 所选因子窗口
2. 例：只用 momentum60 → hist 最低可设 60 + 60 = 120
3. 使用了 dist_52w_high → hist 必须 ≥ 300

## 常见误区

| 误区 | 纠正 |
|------|------|
| hist = 回测长度 | hist 是数据窗口，回测长度由起止日决定 |
| hist 越大越好 | 越大拉取数据越慢，按需设置即可 |
| 短回测区间应该用短 hist | 因子窗口与回测区间无关，取决于选择的因子类型 |

## 数据流

```
前端 hist ──→ GET /api/quote/kline?days=hist ──→ 获取 K 线数组
                                                    ↓
                                              因子计算（需往前看 hist 天）
                                                    ↓
                                              回测调仓（只在起止日之间）
```
