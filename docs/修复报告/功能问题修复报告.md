## 二、逐条修复说明与验证方法

### P1 北交所单只股票导入自选 ✅

**修改内容**
- `frontend/src/utils/format.js`：`normalizeCode` 支持 `920xxx / 8xxxxx / 4xxxxx / bj` 前缀 → 归一化为 `bj` 代码（920 判断先于 sh 的 9）；`stripPrefix` 同步支持 `bj`。
- `QuoteView.vue`：提示文案改为"6 位数字或 sh/sz/bj 前缀"。
- `backend/app/adapters.py`：`_eastmoney_code` 按代码前缀区分北交所；`fetch_kline` 对 bj 代码腾讯返回空时自动降级新浪日K（920 全历史）→ 东财日K（8 开头旧历史）。

**验证方法**
1. 启动后端 + 前端，进入「行情」页。
2. 输入 `830799` 或 `920799` 或 `bj920799`，回车 → 应成功加入自选并显示行情（不再提示"代码格式错误"）。
3. 选股/回测页板块下拉选「北交所」→ 候选池正常拉取。

### P2 期货数据加入模型计算 ✅

**修改内容**
- `adapters.py`：新增 `fetch_future_kline`（新浪期货日K）+ `FUTURE_UNIVERSE` 主力连续合约池（中金所 + 商品全品种）。
- `ml.py`：`build_dataset` / `score_latest` / `backtest_model` 增加 `asset_class: a-share|future` 分支——future 时候选池取期货主力连续合约、K 线走期货适配器、跳过 ST/涨跌停约束。
- 路由层：`routers/ml.py`（evaluate/train/optimize/score/backtest）、`routers/selection.py`（选股/回测）、`routers/jobs.py`（异步任务）均透传 `assetClass`。
- 前端：`MLView.vue`、`BacktestView.vue` 增加「资产类别」下拉（A股 / 期货）。

**验证方法**
1. ML 页：资产类别选「期货（主力连续）」→ 候选池填 20~30 → 点「评估(CV)」→ 应成功构建数据集并出 OOS IC（此前直接抛错或只算 A 股）。
2. 训练并落盘一个期货模型 → 「ML回测」应返回期货分层回测结果。
3. 主回测页：资产类别选「期货」→ 运行分层回测（期货无涨跌停约束，回测正常完成）。

### P3 新增"基础因子" ✅（本次增强）

**修改内容**
- 此前（上个提交）：`FactorView.vue` 已有「表达式因子」创建入口（安全 AST 表达式合成新因子），保存后选股页以 `uf:ID` 引用参与打分。
- 本次新增：`FactorView.vue` 增加「**加权组合因子**」构建器——勾选任意内置基础因子 + 填权重，保存为 `kind=composite` 的自定义因子（落 `user_factors`），与内置因子同等参与选股加权打分。

**验证方法**
1. 因子页 →「新建因子（加权组合）」→ 名称填"价值动量"，给 `momentum=1.0`、`pe=-0.5` 设权重 → 保存。
2. 选股页 → 因子列表中应出现 `uf:{id} 价值动量`，勾选后运行选股 → 打分正常。
3. 表达式因子同样可用（`momentum - volatility*0.5` 等），选股页勾选 `uf:ID` 生效。

### P4 人造/手动模型 ✅（本次实现）

**修改内容**
- `ml.py`：
  - 新增 `_ManualModel` 包装类（实现 `.predict(X)` 与 `feature_importances_`，predict 内部先做截面 z-score 再按权重线性合成 + 阈值偏移），与自动训练模型**完全同构**；
  - `create_manual_model(name, featureWeights, threshold, rule)`：落盘 `manual_<ts>.joblib` + sidecar JSON，随后**打分/回测/盯盘调度零改动复用**；
  - `manual_feature_options()`：返回可选的 22 个技术因子清单。
- `routers/ml.py`：新增 `POST /api/ml/models/manual`、`GET /api/ml/manual/features`。
- `MLView.vue`：新增「新建人造模型」卡片（模型名称 + 每个因子权重 + 阈值偏移 + 规则说明）。

**验证方法**
1. ML 页 →「新建人造模型」→ 名称"动量+低波"、给 `momentum=1`、`volatility=-0.5` → 创建 → 出现在"已训练模型"列表（`manual_*`）。
2. 对该模型点「打分选股」→ 应返回预测分排序（按权重合成的逻辑分数）。
3. 对该模型点「ML回测」→ 分层回测正常出图。
4. 盯盘页 → 信号引擎选「ML模型打分」→ 选择该 manual 模型 → 保存配置 → 开启调度 → 信号按模型分生成（见 P5）。

### P9 ML 样本不足友好处理 ✅（本次实现）

**修改内容**
- `ml.py build_dataset`：统计并输出**结构化报错**——候选池总数 / K 线不足被剔除数 / 因子缺失切片数 + 参数调整建议（原为裸 `有效样本不足`）。
- `ml.py evaluate_dataset`：CV 分不出有效折时**自动降级折数**（n_splits 递减重试，日志记录）；仍失败时输出当前样本数 + 建议（调小折数 / 减小 gap / 增大池子）。
- `ml.py backtest_model`：`有效股票样本不足`、`有效截面样本不足` 均带实际数量与建议。

**验证方法**
1. ML 页把候选池填 1、历史填 60 → 点「评估(CV)」→ 报错信息包含"候选池 1 只，K线历史不足 X 日被剔除 X 只…请增大候选池规模"等具体指引（此前为裸异常）。
2. 正常参数（候选池 80、历史 240）→ 评估正常；若折数过大（如 10 折、样本少）时观察后端日志出现"CV 折数自动降级"。

### P10 回测报告生成功能（完整化） ✅（本次实现）

**修改内容**
- 新增 `backend/app/reporting.py`：
  - `render_html`：自包含 HTML **内嵌 ECharts 图表**（多空累计收益/回撤曲线、分组柱状图、IC/RankIC 时序），含打印样式；
  - `render_excel`：绩效指标/分组收益/多空净值/IC 序列多 sheet；
  - `render_pdf`：reportlab + `STSong-Light` 中文字体（已加入 `requirements.txt`），无外挂字体文件依赖；
  - `store_backtest_report`：回测完成**自动生成 HTML 报告文件 + 登记 `backtest_runs` 历史**（新增 `result_json` 列存全量结果）。
- `db.py`：`backtest_runs` 增加 `result_json` 列；`create_backtest_run` 支持存全量结果；`list_backtest_runs` 支持不过滤用户。
- `routers/reports.py`：
  - 导出支持 `format=pdf`（reportlab 缺失时降级打印样式 HTML）；
  - 新增 `GET /api/reports/runs`（历史列表）、`GET /api/reports/runs/{id}`（下载 HTML）、`POST /api/reports/runs/{id}/regenerate?fmt=html|excel|pdf`（从历史结果一键重生成）、`DELETE /api/reports/runs/{id}`；
  - 新增 `POST /api/reports/select`（**选股结果报告** html/excel/pdf）。
- 回测自动存档接入：`selection.py run_backtest`（因子 + 模型两条路径）、`ml.py backtest_model`（含 jobs 异步路径）完成后自动：`BacktestView.vue` 新增「导出PDF」按钮 + 「**报告历史**」面板（下载 HTML/Excel/PDF、删除）；`MLView.vue` 新增「导出PDF」；`SelectView.vue` 选股结果区新增「报告：HTML/Excel/PDF」按钮；`api/client.js` 新增 `downloadGet`。

**验证方法**
1. 运行任意一次分层回测（主回测页或 ML 页）→ 点「导出PDF」→ 下载 `.pdf` 文件（含中文 KPI + 表格）。
2. 回测完成后点「报告历史」→ 出现刚完成回测的记录（含时间/累计收益/Sharpe）→ 分别点 HTML/Excel/PDF 下载，文件内容与本次回测一致。
3. 删除该记录 → 文件与历史记录一并清除。
4. 选股页跑一次选股 → 结果区点「报告：HTML/Excel/PDF」→ 下载选股榜单报告。
5. （联网环境）下载的 HTML 报告打开后可见净值/回撤/分组/IC 图表（ECharts CDN）。
